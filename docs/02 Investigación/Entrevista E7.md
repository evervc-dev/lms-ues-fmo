# Entrevista E7 · Docente

Instrumento 1, guía de entrevista a docentes. Ver [[Metodología]].

## Respuestas
| N.º | Pregunta | Respuesta |
|---|---|---|
| 1 | ¿Funcionalidades que más utiliza? | Moodle: documentos, enlaces y exámenes. |
| 2 | ¿Limitaciones encontradas? | Controlar las actividades completadas es posible pero tedioso. |
| 3 | ¿Cómo afectan su desempeño? | No hay control de seguimiento. |
| 4 | ¿Qué funcionalidades hacen falta? | Un editor o gestor de código dentro de la plataforma. |
| 5 | ¿Problemas al pasar asistencia manual? | Proceso manual en papel bond. |
| 6 | ¿Cómo validan que los anotados estén presentes? | Las hojas se traspapelan o se pierden. |
| 7 | ¿Reportes que más usa? | Conteo. |
| 8 | ¿Formato de retroalimentación y tiempo por estudiante? | Reportes de calificaciones con descarga para publicarlas. |
| 9 | ¿Qué le preocupa del QR para asistencia? | Comentarios sobre los formatos de pregunta y respuesta. |
| 10 | ¿Algo más? | Considerar fallas de internet con el QR; los archivos se pierden al reiniciar el servidor. Notebooks de Python embebidos; IA para mapear contenidos. |

## Hallazgos clave
- Seguimiento de lo completado.
- Archivos que se pierden al reiniciar: respaldo y almacenamiento persistente.
- Editor de código e IA: fuera de alcance.
