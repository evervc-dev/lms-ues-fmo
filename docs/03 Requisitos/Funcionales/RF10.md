# RF10 · Estadísticas de oferta académica

> **Características:** Proyección histórica de grupos necesarios por período.

## Descripción
Calcula el número de estudiantes ingresados, egresados, aprobados y reprobados por asignatura y período, para que la jefatura proyecte cuántos grupos como máximo necesitará el siguiente período.

## Criterios de aceptación
- **Dado** un período cerrado, **entonces** muestra por asignatura los ingresados, egresados, aprobados y reprobados.
- **Dado** el histórico, **entonces** propone el número máximo de grupos para el siguiente período, que la jefatura puede ajustar.

## Reglas de negocio
- Hace falta definir la fórmula de proyección con la jefatura.

## Origen en la investigación
- [[Entrevista jefatura]]: se usa esta estadística para pronosticar el máximo de grupos.
