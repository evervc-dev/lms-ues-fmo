# RF11 · Gestión de materiales, unidades y recursos

> **Características:** Contenido organizado por unidades o semanas, con navegación paginada.

## Descripción
El docente crea unidades dentro de su asignatura y en cada una publica documentos (PDF, Word), carpetas, páginas con texto enriquecido, videos (enlaces a YouTube o Drive), enlaces externos y presentaciones, con título, descripción y metadatos. El acceso depende del rol. Se pueden reutilizar contenidos de períodos anteriores y buscar o filtrar por asignatura, unidad o tipo.

## Criterios de aceptación
- **Dado** un estudiante no matriculado en la asignatura, **cuando** abre un recurso, **entonces** se rechaza.
- **Dado** el docente, **cuando** arrastra un archivo a la unidad, **entonces** se sube y valida tipo y tamaño.
- **Dado** un PDF, **entonces** el docente elige si se descarga o se ve incrustado en la plataforma.
- **Dado** un estudiante, **cuando** busca por nombre o tipo, **entonces** encuentra el recurso en menos de 3 s.
- **Dado** las unidades del curso, **entonces** se muestran como acordeones colapsables.
- **Dado** el docente, **cuando** sube una carpeta, **entonces** se conserva su estructura y el estudiante la descarga completa como .zip.
- **Dado** el editor de páginas, **cuando** el docente aplica negrita, cursiva o centrado, **entonces** se guarda como HTML sanitizado, sin scripts.
- **Dado** un recurso o una unidad eliminados, **entonces** van a la papelera y el docente puede restaurarlos durante 30 días; después se borran definitivamente.

## Reglas de negocio
- Papelera: borrado lógico (soft delete) con purga automática a los 30 días.
- **Qué borra la purga (decidido el 24/10/2026):** se elimina el archivo del disco y se vacía el contenido del recurso (`file_path`, `url`, `html_content`, `pdf_mode`), pero **la fila se conserva**. El [[Modelo entidad-relación]] exige que los logs de acceso nunca se borren (FK `RESTRICT`), y borrar el recurso obligaría a borrarlos: así desaparece el material y se conserva la analítica de [[RF13]].
- El HTML se sanitiza en el servidor para evitar XSS ([[RNF01]]).

## Origen en la investigación
- [[Hallazgos]]: el 60.7 % de los estudiantes tiene dificultad para encontrar materiales (n = 28).
- [[Entrevista E1]]: estructura por unidad, tema y subtema.
