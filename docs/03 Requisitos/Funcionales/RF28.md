# RF28 · Registro de asistencia mediante código temporal

> **Características:** Código temporal asociado a un solo estudiante.

## Descripción
Si un estudiante no puede registrarse con el QR, el docente genera durante la sesión abierta un código temporal **solo para ese estudiante**, vigente 30 segundos y de un solo uso. Se verifica que el estudiante pertenezca al grupo y que no tenga ya un registro en la sesión.

## Criterios de aceptación
- **Dado** un código con más de 30 s, **entonces** se rechaza.
- **Dado** un código usado por otra cuenta, **entonces** se rechaza.
- **Dado** un código ya usado, **entonces** no se puede reutilizar.
- **Dado** un estudiante con asistencia ya registrada en la sesión, **entonces** no se genera el código.
