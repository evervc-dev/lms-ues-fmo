# RF26 · Configuración de áreas de asistencia

> **Características:** Coordenadas del campus de la UES FMO.

## Descripción
Se configuran las áreas geográficas autorizadas para registrar asistencia con el teléfono, por coordenadas y radio o por una zona del campus UES FMO. Al registrar, se compara la ubicación del dispositivo con el área y se rechaza si está fuera.

## Criterios de aceptación
- **Dado** el Administrador, **cuando** define un área por centro y radio o por polígono, **entonces** queda disponible para las sesiones de asistencia.
- **Dado** una ubicación fuera del área, **entonces** el registro se rechaza ([[RF20]]).

## Reglas de negocio
- La precisión del GPS en interiores varía; el radio debe tener margen. En un polígono el margen va dentro del dibujo ([[ADR-055 Leaflet y OpenStreetMap para las áreas de asistencia]]).
- Las áreas **no se asignan a una carrera, asignatura ni docente**: el QR de cualquier sesión presencial se acepta dentro de cualquier área activa, como una geocerca del campus. Lo decidió el usuario el 30/10/2026 ante el informe de QA de la sesión 4, y la pantalla de áreas lo explica.
