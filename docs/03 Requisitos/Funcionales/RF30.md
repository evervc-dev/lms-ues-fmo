# RF30 · Foros de discusión

> **Características:** Foros por curso con hilos anidados.

## Descripción
Cada curso tiene foros donde se crean hilos y se responde a cualquier comentario, formando un árbol. El docente modera: fija, cierra u oculta mensajes.

## Criterios de aceptación
- **Dado** un comentario, **cuando** alguien responde, **entonces** la respuesta aparece anidada bajo él.
- **Dado** el docente, **cuando** oculta un mensaje, **entonces** deja de verse para los estudiantes y queda registrado.
- **Dado** un hilo cerrado, **entonces** no admite respuestas nuevas.
- **Dado** un mensaje nuevo, **entonces** se notifica según las preferencias ([[RF23]]).

## Reglas de negocio
- Los mensajes del foro pueden ser regla de finalización automática ([[RF18]]).
- El contenido se sanitiza como el editor HTML ([[RF11]]).

## Origen en la investigación
- [[Entrevista E6]]: foros de pregunta y respuesta y de comentarios.

## Notas
- No es mensajería interna; esa quedó fuera de alcance.
