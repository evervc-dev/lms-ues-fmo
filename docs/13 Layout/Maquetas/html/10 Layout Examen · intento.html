¿Cuál es la complejidad temporal en el peor caso para el algoritmo de ordenamiento Quicksort cuando el pivote se elige de manera determinista en un arreglo previamente ordenado?

quicksort_deterministic.cpp
C++17 
int partition(int arr[], int low, int high) {
    int pivot = arr[high]; // Selección del último elemento
    int i = (low - 1);

    for (int j = low; j <= high - 1; j++) {
        if (arr[j] < pivot) {
            i++;
            std::swap(arr[i], arr[j]);
        }
    }
    std::swap(arr[i + 1], arr[high]);
    return (i + 1);
}
