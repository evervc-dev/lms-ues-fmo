Error de segmentación (SIGSEGV) al desreferenciar puntero doble en función recursiva

CO
Cristian Eduardo Ortiz Estudiante
Carné: OC22009 · Ingeniería de Sistemas Informáticos · Publicado hace 2 horas

Estimado docente y compañeros, reciba un cordial saludo. Durante la implementación de la Guía Práctica #4 sobre Árboles Binarios de Búsqueda (ABB), me he topado con un fallo de segmentación (Segmentation fault: 11 / SIGSEGV) cuando ejecuto la inserción sucesiva de nodos en memoria dinámica.

He verificado con el depurador GDB y el colapso se genera justamente al evaluar la rama izquierda cuando la raíz apunta a nullptr. Adjunto el extracto de mi función recursiva:

arbol_binario.cpp · línea 48-62 
void insertar(TreeNode** raiz, int valor) {
    if (*raiz == nullptr) {
        // ERROR crítico observado en GDB:
        (*raiz)->izq = nullptr;  <-- SIGSEGV: Se desreferencia *raiz siendo nulo
        (*raiz)->der = nullptr;
        *raiz = new TreeNode{valor, nullptr, nullptr};
        return;
    }
    
    if (valor < (*raiz)->dato) {
        insertar(&((*raiz)->izq), valor);
    } else {
        insertar(&((*raiz)->der), valor);
    }
}

Agradezco de antemano cualquier sugerencia sobre el orden correcto de invocación para asegurar que la raíz del subárbol quede debidamente asignada en el puntero original de la función main().

Estimado Br. Cristian Ortiz, excelente planteamiento técnico.

El problema de su código radica con exactitud en que usted está intentando desreferenciar los campos miembros (*raiz)->izq y (*raiz)->der cuando la condición previa confirma que *raiz es nullptr. En memoria virtual, usted solicita la dirección base 0x0 con desplazamiento de estructura, desencadenando la señal SIGSEGV de protección de memoria por parte del kernel.

Para solucionarlo, usted debe primero reservar el espacio del bloque con el operador new y ligarlo a *raiz, asignando después los punteros nulos en el constructor o lista de inicialización:

task_alt Solución recomendada según estándar C++14/C++17 
void insertar(TreeNode** raiz, int valor) {
    if (*raiz == nullptr) {
        // 1. Reservar memoria primero y enlazar directamente al puntero doble
        *raiz = new TreeNode{valor, nullptr, nullptr};
        return;
    }
    
    // 2. Enrutamiento recursivo en el árbol binario
    if (valor < (*raiz)->dato) {
        insertar(&((*raiz)->izq), valor);
    } else if (valor > (*raiz)->dato) {
        insertar(&((*raiz)->der), valor);
    }
    // Nota: Si valor == (*raiz)->dato, evitamos llaves duplicadas.
}

Recomendación para entrega: No olviden implementar la función complementaria de liberación recursiva destruirArbol(TreeNode* nodo) para garantizar que no existan fugas reportadas en la prueba final con Valgrind.
