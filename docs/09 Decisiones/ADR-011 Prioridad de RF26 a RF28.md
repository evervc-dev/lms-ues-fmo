# ADR-011 · Prioridad de RF26, RF27 y RF28

## Contexto
Los tres requisitos no tienen prioridad en el documento.

## Recomendación
**Alta para los tres.** Son las validaciones que hacen seguro a [[RF20]] (prioridad Alta), junto con el token rotativo ([[ADR-028 QR rotativo]]).

## Decisión
**Alta** para [[RF26]], [[RF27]] y [[RF28]]. *Decidido por el equipo el 10/10/2026.*
